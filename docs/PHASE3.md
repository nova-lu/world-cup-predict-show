# Phase 3: 世界杯数据助手 · 完整增强计划

## 一、参考网站核心功能分析

### 1. Cup26Matches (cup26matches.com)
- 冠军概率排行榜 + 阶段矩阵（R32→冠军的前置概率）
- 比赛预测日历（带赔率对比）
- 深度分析博客
- 模型方法论说明
- 嵌入式 widget

### 2. Outliners (worldcup2026-prediction-market.vercel.app)
- **交互式蒙特卡洛模拟器**（1K-100K 可调，Web Worker 浏览器端运行）
- 模拟后仪表盘：冠军概率 + Wilson 95% CI、阶段矩阵、淘汰赛树、小组排名
- **预测市场 Demo**（$1000 模拟金、YES/NO 交易）
- **回测验证**（2014/2018/2022 三届世界杯 + 12 个指标）
- 伤病/停赛影响模型
- 点球历史模型（贝叶斯收缩）
- 最近状态调整（1 年回溯 ELO）

### 3. mikobinbin 预测器
- 比分概率矩阵（Poisson 分布）
- 玄学因子（易经/道德经风格）→ 趣味性
