     🔴 问题 1 (T1): eloSnapshot.js manifest 查找逻辑 BUG

     发现: loadEloSnapshot() 从 manifest 列表尾部（最早的）向前扫描，但 manifest 是按日期降序排列（最新的在前）。当存在 3+ 个 manifest
     时，会返回最早符合条件的（e.g. 6月29日的）而非最新但在目标日期前的（e.g. 6月30日的）。

     影响: 随着赛事推进积累更多 manifest，历史回测会使用越来越早的数据，而非最接近比赛日期的数据点。

     修复: 改为从头部（最新）向尾部扫描，取第一个 m.date < targetDate 的 manifest。
     🔴 问题 2 (T5): 预测数据流断裂 — overUnder/btts 字段丢失

     发现: server/ml/inference/predictor.js 的 predictMatch() 正确返回了 overUnder、btts、topScores、risk、coverage 等字段，但回测 predictor.js
